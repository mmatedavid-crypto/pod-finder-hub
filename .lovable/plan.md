## Scope (Phase 1 + 4 + 6)

Port the Tinder-style swipe onboarding, aura/Podiverzum profile result page, share page, cookieless landing analytics, and fix Google OAuth redirect. **English-only**, **GPT-5.5** for any user-facing copy translation. **Szirmai Marcell / HU person merge skipped** (not relevant on .com).

## Reality check (important)

The .hu version of the swipe runs on a `taste_cards` table that holds **hundreds of seeded cards** (broad domain + refine cards), each with a **768-dim card embedding** generated by a `taste-card-embedder` edge function. The .com project has **none** of this — table, RPC, edge fn, and content all missing. So porting the page UI without seeding cards = a blank swipe.

This plan ships:
- The full UI + lib + tables + RPCs + edge fn infra
- A **starter English seed of ~14 broad domain cards** (Politics, Economy, Science, Culture, Sports, Health, Tech, Lifestyle, Literature, Food, Travel, True Crime, Business, Comedy) so the swipe is functional on day one
- A small set of refine cards (~10–15) so the second stage isn't empty

Growing the catalog to .hu-parity (50+ refine cards across all domains) is a follow-up — out of this scope.

## Database migrations

### Tables (with RLS)
```text
landing_events
  id, anonymous_session_id, event_name, utm_source/medium/campaign/content/term,
  landing_variant, path, referrer_domain, device_type, meta jsonb, created_at
  RLS: insert public; select admin-only

taste_cards
  id, title, subtitle, image_url, stage ('broad'|'refine'),
  sensitivity_level ('safe'|'sensitive'), priority int,
  topic_tags text[], mood_tags text[], format_tags text[],
  psych_tags text[], archetype_tags text[],
  text_for_embedding text,
  card_embedding vector(768),
  catalog_fit_score real, top_episode_similarity real,
  active boolean default true, validation_status text default 'pending',
  created_at, updated_at
  RLS: select public WHERE active=true; admin write

taste_interactions
  id, anonymous_session_id, user_id (nullable),
  card_id fk, action ('like'|'skip'|'super'),
  swipe_index int, created_at
  RLS: insert public; select admin-only
```

### RPCs
- `get_active_taste_cards(p_limit int)` — returns active cards with `card_embedding::text` (parsed client-side)
- `match_episodes_by_taste_vector(p_user_vector vector, p_negative_vector vector, p_exclude_episode_ids uuid[], p_limit int)` — uses existing `episode_embeddings` HNSW, returns top-N with `final_score`, joins podcast + topics/category for re-rank

### Seed data
- ~14 English broad-domain cards + ~12 refine cards via INSERT (no embeddings yet — set `validation_status='pending'`, embedder edge fn fills them)
